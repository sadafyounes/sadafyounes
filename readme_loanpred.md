# Loan Prediction Project

This project predicts loan approvals using **Random Forest** and **k-NN**, with a comparison of their performance.

---

## Overview
- Predicts loan approvals based on features like income, credit history, and more.
- Comparison shows Random Forest outperforms k-NN.

---

## Dataset
- Includes features: Applicant Income, Loan Amount, Credit History, etc.
- Preprocessed by handling missing values, encoding categorical variables, and scaling features.

---

## Results
- Random Forest: Accuracy 76%, F1-Score 75%.
- k-NN: Accuracy 75%, F1-Score 74%.
- Conclusion: Random Forest is more accurate and reliable.

---

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/sadafyounes/loan-prediction.git
   cd loan-prediction
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the script:
   ```bash
   python loan_prediction.py
   ```
